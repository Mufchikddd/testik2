# Левитация — каталог дорам (этап 1)

Информационный сайт-каталог: Next.js 15 (App Router) + Tailwind CSS 3, тёмная тема.
Плеер и видео в этот этап не входят.

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # впишите TMDB_API_KEY (бесплатно: themoviedb.org/settings/api)
npm run dev                  # http://localhost:3000
```

Без ключа сайт работает на мок-данных (13 дорам), так что его можно показывать сразу.

## Как устроены данные

```
src/lib/
  types.ts            модель Drama, CatalogQuery/CatalogPage и контракт DramaProvider
  query.ts            разбор и сборка URL-параметров (?q=&year=&rating=&sort=&lang=&page=), листание в памяти
  config.ts           переменные окружения, выбор провайдера
  http.ts             fetch с таймаутом, редакцией ключей в ошибках
  cache.ts            кэш: память + JSON-файл + устаревшие данные при сбое
  catalog.ts          getCatalogPage() / getDrama(): кэш → источник → мок
  providers/
    tmdb.ts           основной источник (название, постер, описание, год, рейтинг, актёры)
    dracin.ts         экспериментальный адаптер DracinAPI (нужен ключ, сверьте формат ответа)
    mock.ts           офлайн-фолбэк, данные в data/mock-dramas.json
```

**Вся база, а не выборка.** Каталог листается постранично (по 20 карточек), а поиск, год, рейтинг,
сортировка и страна выполняются на стороне TMDB. Все фильтры живут в адресной строке, поэтому
результатом можно поделиться ссылкой, а кнопка «назад» работает как ожидается.

Ограничения TMDB: один запрос достаёт не больше 500 страниц (10 000 тайтлов). Если дорам в выборке больше,
сузьте её годом или рейтингом. Поиск по названию идёт по базе TMDB, но язык и рейтинг для него
дофильтровываются на нашей стороне, поэтому на отдельных страницах поиска карточек бывает меньше 20.

**Что считается дорамой.** Страна выбирается языком оригинала (`ko`, `zh`, `ja`, `th`), а реалити, ток-шоу, новости,
документальные и детские программы отсеиваются по жанрам (`TMDB_EXCLUDE_GENRES`).

**Цепочка надёжности:** свежий кэш → запрос к API → устаревший кэш (если API лёг) → мок-данные.
Каждая страница каталога кэшируется отдельно. Время жизни кэша: `CATALOG_TTL_SECONDS`.

**Список vs. карточка.** Список берётся без актёров. Полная карточка с актёрами запрашивается
при первом открытии страницы дорамы и кэшируется отдельно.

**JSON-кэш на диске** по умолчанию лежит во временной папке ОС (`CACHE_DIR` меняет путь).
На read-only хостингах (в т.ч. Vercel) запись молча пропускается и остаётся кэш в памяти.

## Плеер и серии (этап 2)

Серии берутся из **официального JSON-файла студии**, никакого парсинга чужих страниц. Формат:

```json
[
  { "episode": 1, "title": "Серия 1", "url": "https://le-vitation.tv/video/ep1.m3u8", "dramaId": "tmdb-96648" }
]
```

`dramaId` необязателен: по нему серия показывается в карточке дорамы в каталоге. Без него она видна только в разделе «Смотреть».

- Источник: `EPISODES_FEED_URL` (только https). Пока он не задан, серии читаются из `data/episodes.json` в проекте (тестовые данные с тестовым HLS-потоком, привязаны к `dramaId: "tmdb-96648"`).
- Файл перечитывается раз в 5 минут (`EPISODES_TTL_SECONDS`), поэтому новые серии появляются сами.
- Принимаются только `https`-ссылки на `.m3u8` и `.mp4` с хостов из `EPISODES_ALLOWED_HOSTS`. Остальные записи отбрасываются.
- Если файл студии недоступен и кэша нет, сайт показывает «список недоступен», а не тестовые видео.
- Страницы: `/watch` (все серии), `/watch/<id>` (плеер, предыдущая и следующая серия).

**CORS.** Если видео лежит на другом домене, чем сайт, сервер студии должен отдавать заголовок
`Access-Control-Allow-Origin` с адресом сайта, иначе браузер заблокирует HLS. После переезда сайта на `le-vitation.tv` это не нужно.

## Как добавить источник

1. Создайте `src/lib/providers/<name>.ts` и реализуйте `DramaProvider` (`fetchPage`, `fetchDrama`),
   приведя ответ к модели `Drama`.
2. Добавьте имя в `PROVIDER_NAMES` (`types.ts`) и в `registry` (`providers/index.ts`).
3. Если картинки с нового CDN — добавьте хост в `next.config.mjs` и `OPTIMIZED_IMAGE_HOSTS` (`utils.ts`);
   иначе они подгрузятся обычным `<img>`.
4. Выберите его: `DRAMA_PROVIDER=<name>`.

## Другая страна по умолчанию

В фильтре «Страна» доступны корейские, китайские, японские и тайские. Какая открывается первой, задаёт `TMDB_ORIGINAL_LANGUAGE`. Язык описаний — `TMDB_LANGUAGE`.
